# Сайт «Беларусь в масштабе»

Обычный статический сайт: HTML, CSS и JavaScript без серверной части. Работает на любом бесплатном хостинге.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Главная: все миниатюры, поиск, планируемые миниатюры с голосованием, о проекте |
| `building.html` | Страница здания (одна на все 22): фото, архивные фото, описание. Открывается как `building.html?id=mirsky` |
| `qr.html` | Только для вас: создаёт QR-коды и тексты табличек для печати |
| `data.js` | **Все тексты, фото и список планируемых миниатюр.** Менять нужно в основном этот файл |
| `style.css`, `app.js` | Оформление и общие функции (можно не трогать) |
| `img/miniatures/` | Сюда кладутся рендеры миниатюр |

## Как посмотреть у себя на компьютере

Дважды щёлкните `index.html`. Страница `qr.html` без интернета не заработает: она подгружает библиотеку QR-кодов.

## Как опубликовать (бесплатно)

Нужен публичный адрес, иначе QR-коды на табличках никуда не приведут. Самый простой путь, GitHub Pages:

1. Создайте аккаунт на github.com и новый репозиторий (например, `belarus-miniatures`), тип **Public**.
2. Нажмите **Add file → Upload files** и перетащите внутрь **содержимое папки** (файлы и папку `img`), затем **Commit changes**.
3. Откройте **Settings → Pages**. В **Branch** выберите `main` и папку `/ (root)`, сохраните.
4. Через 1–2 минуты сайт будет по адресу `https://ваш-логин.github.io/belarus-miniatures/`.

Альтернативы: Netlify (перетащить папку на app.netlify.com/drop) или Cloudflare Pages.

## Как добавить фото

**Рендер миниатюры** (появится на карточке и вверху страницы здания): сохраните его как `img/miniatures/<id>.jpg`. Например, `img/miniatures/mirsky.jpg`. Идентификатор `id` каждого здания записан в `data.js`.

**Настоящие и архивные фотографии** (на странице здания): положите файлы, например, в `img/mirsky/`, и впишите их в `data.js`:

```js
{ id: "mirsky", name: "Мирский замок", ...,
  photos:  ["img/mirsky/1.jpg", { src: "img/mirsky/2.jpg", caption: "Вид с северной стороны" }],
  archive: [{ src: "img/mirsky/old1.jpg", caption: "Фото начала XX века" }] }
```

Фото лучше сжимать до 1600 px по длинной стороне (JPG), иначе страницы будут грузиться медленно на телефоне.

## Планируемые миниатюры и голосование

В `data.js` есть список `PLANNED`. **Сейчас там примерные три здания. Замените их на свои.**

Голосование работает в двух режимах:

- **Без настройки** (`VOTE_FORM_URL = ""`): человек отмечает нужные варианты, выбор запоминается только в его браузере. Общий подсчёт при этом **не ведётся**: это показ интерфейса.
- **С общим подсчётом**: создайте Google Форму с вопросом «Какие миниатюры вы хотели бы увидеть?» (вопрос с флажками, варианты те же, что в `PLANNED`), нажмите **Отправить → ссылка** и вставьте ссылку в `VOTE_FORM_URL` в `data.js`. Кнопки «Хочу увидеть» заменятся кнопкой «Проголосовать», а результаты вы увидите в самой форме.

## QR-коды и таблички

1. Опубликуйте сайт (см. выше).
2. Откройте `https://ваш-адрес/qr.html`, адрес сайта подставится сам. Нажмите **Создать**.
3. Появится 23 карточки: QR-код сайта парка (для входа в парк) и таблички всех зданий с названием, годом, коротким текстом и QR-кодом на страницу здания.
4. Кнопка **Печать** выводит их на листы (по две в ряд), а на каждой карточке можно скачать QR отдельно в PNG или SVG.
5. **Проверьте один QR телефоном** до печати всех табличек. QR на табличке должен быть не меньше 2×2 см.

Если вы смените адрес сайта, QR-коды придётся перепечатать: адрес зашит в код. Поэтому для печати лучше сразу использовать постоянный адрес.

## Что изменить под себя

- Раздел «О проекте»: `ABOUT` в `data.js`.
- Короткие тексты табличек: `SHORT` в `data.js`.
- Полные описания, год, стиль: поля `desc`, `year`, `style` у каждого здания.
- Цвета: переменные в начале `style.css`.
